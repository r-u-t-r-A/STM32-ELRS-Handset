# STM32-ELRS-Handset
Code for DIY Handset with ELRS. HACK_TX is current workname of this project. 
CRSF related code is based on work of kkbin from ELRS discord, documentation of CRSF commands was created by cooldan from ELRS discord.

why v8 vibed? this code has been created with help of cursor AI. It has proven suprisingly useful. Previous versions were written without help of LLMs.

This firmare has a menu system allowing for dynamiclly loading ELRS config menu from the tx module just like ELRS lua script does. System has overall improvements, remains to be tested if there are bugs.
